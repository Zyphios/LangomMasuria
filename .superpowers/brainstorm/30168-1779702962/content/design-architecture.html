Architektura — Lagom Masuria

Sekcja 1/4 — Przegląd systemu. Zatwierdź zanim przejdziemy dalej.

Docker Compose — 3 kontenery

FRONTEND :3000
React + Vite + TS
  • Tailwind CSS
  • react-router-dom v6
  • react-i18next (PL/EN)
  • react-query (dane z API)
  • Panel admina (trasa /admin)
BACKEND :4000
Express.js + TS
  • Prisma ORM
  • REST API (/api/*)
  • Nodemailer (SMTP)
  • JWT — autentykacja admina
  • Zaślepka PayU (/api/payment)
  • Zod — walidacja danych
DATABASE :5432
PostgreSQL 16
  • bookings
  • blocked_dates
  • contact_messages
  • gallery_images
  • pricing_seasons
  • admin_users
Frontend → REST API (fetch) → Backend → Prisma → PostgreSQL
Backend → Nodemailer → SMTP (e-mail do właściciela)
Backend → zaślepka PayU → (prawdziwe płatności w przyszłości)
Panel admina: JWT token w localStorage, chronione trasy na froncie i backendzie
