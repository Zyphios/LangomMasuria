API i Panel Admina — Sekcja 3/4

REST API endpoints + funkcje panelu admina. Zatwierdź zanim przejdziemy dalej.

REST API (Express.js :4000)

🌐 PUBLICZNE
GET/api/availability?month&year → zajęte daty
POST/api/bookingsZłóż rezerwację
POST/api/contactWyślij wiadomość
GET/api/galleryLista zdjęć
GET/api/pricingSezony cenowe
POST/api/payment/initZaślepka PayU
POST/api/payment/notifyPayU webhook (stub)
🔐 ADMIN (JWT wymagany)
POST/api/admin/loginZaloguj admina
GET/api/admin/bookingsLista rezerwacji
PATCH/api/admin/bookings/:idZmień status
DELETE/api/admin/bookings/:idUsuń rezerwację
GET/api/admin/messagesWiadomości kontakt.
PATCH/api/admin/messages/:idOznacz jako przeczyt.
POST/api/admin/blocked-datesZablokuj datę
DELETE/api/admin/blocked-dates/:idOdblokuj datę
POST/api/admin/galleryDodaj zdjęcie
DELETE/api/admin/gallery/:idUsuń zdjęcie
PATCH/api/admin/pricing/:idEdytuj cennik

Panel Admina (/admin) — 5 zakładek

📅
Rezerwacje
Lista + zmiana statusu (pending/confirmed/cancelled)
🗓️
Dostępność
Kalendarz — blokuj / odblokuj daty ręcznie
✉️
Wiadomości
Formularz kontaktowy — odczyt + oznacz jako przeczytane
🖼️
Galeria
Dodaj URL / usuń / zmień kolejność
💰
Cennik
Edytuj ceny sezonów i daty obowiązywania

E-mail powiadomienia (Nodemailer)

📧 Nowa rezerwacja → e-mail do właściciela z datami, gościem, kwotą
📧 Nowa wiadomość → e-mail do właściciela z treścią formularza
📧 Potwierdzenie → e-mail do gościa po zatwierdzeniu rezerwacji przez admina
Konfiguracja przez .env: SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, OWNER_EMAIL
